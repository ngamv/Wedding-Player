# Raccordement du site

Confirme le site et l’objectif, puis collecte les faits et les preuves disponibles.
Inventorie URL, hébergement, CMS, dépôt, propriétaires d’accès et environnement de test. Distingue les accès vérifiés des accès à obtenir. Prépare le plan de raccordement et les critères de réception.

Livre les actions, les responsables pressentis, les critères de validation et les points à arbitrer.
Trace le résultat dans Site web après validation puis intervention réelle.
Les publications, déploiements, changements DNS et modifications de production exigent une validation explicite.
